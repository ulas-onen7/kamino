# Contributing

Kamino has one maintainer, working on this in spare time. Response time is best-effort — please
be patient.

## Bug reports

Run `kamino doctor` and paste its output into the issue. That single command surfaces most of
what's needed to diagnose a problem (registry state, host integration status, environment
checks) faster than a back-and-forth would.

## Pull requests

Small, focused PRs are welcome and get reviewed fastest. For anything larger — a new feature, a
change to the CLI surface, a new host integration — please open an issue first to discuss the
approach before writing the code. That avoids spending effort on something that doesn't fit the
project's direction.

## Legal

No CLA. Contributions are accepted under Apache-2.0, inbound=outbound: by submitting a PR you
agree your contribution is licensed under the same terms as the rest of the project (see
`LICENSE`).
